# GleamCraft

A modern dental care website developed as a team project during our training at the National Telecommunication Institute (NTI).

**Overview**

GleamCraft is a modern dental care website designed to showcase dental clinics, treatments, services, testimonials, and provide users with an interactive browsing experience.

The project focuses on creating a clean, responsive, and user-friendly interface using HTML, CSS, JavaScript, Bootstrap, and responsive web design techniques.

**Description**

GleamCraft includes multiple dental clinic pages with different layouts and sections.

The website includes:

* Hero sections
* About Us sections
* Dental clinic showcases
* Treatments and services
* Testimonials
* Statistics sections
* Interactive FAQ
* Sign In page
* Sign Up page
* Client-side form validation
* Responsive layouts
* CSS animations and hover effects
* Bootstrap components
* Font Awesome icons

The project was developed as a team project, where responsibilities were divided between team members and the different parts of the website were integrated together.

**Interactive FAQ**

I implemented the interactive FAQ section using JavaScript.

The FAQ allows users to click on a question to show or hide its answer.

I worked with:

* `querySelectorAll()`
* `forEach()`
* `addEventListener()`
* `parentElement`
* `nextElementSibling`
* `classList.contains()`
* `classList.add()`
* `classList.remove()`
* Dynamic changes to the FAQ icons

This helped me gain more practical experience with DOM Manipulation, Event Handling, Form Validation, Regular Expressions, and Interactive UI Development.

**Getting Started**

**Dependencies**

* A modern web browser such as Google Chrome, Microsoft Edge, or Firefox
* HTML5
* CSS3
* JavaScript
* Bootstrap
* Font Awesome
* Internet connection for loading external fonts and libraries

**Installing**

* Download or clone the project.
* Make sure the HTML, CSS, JavaScript, and image files remain in their correct locations.
* Make sure all images referenced in the HTML files are available.

**Executing program**

* Open the project folder.
* Open `index.html` with a web browser.

```text
Open index.html
```

* Use the navigation bar to explore the website.
* Explore the different dental clinic pages.
* Try the interactive FAQ section.
* Test the Sign In and Sign Up forms.

**Help**

Make sure the project folder structure is preserved.

The HTML files reference CSS, JavaScript, and image files using relative paths. Moving or renaming these files may cause parts of the website to stop working correctly.
